# Shortcuts

| Category      | Action            | Shortcut / Input                                                                           |
| :------------ | :---------------- | :----------------------------------------------------------------------------------------- |
| **Editor**    | **History**       | <kbd>Ctrl</kbd>+<kbd>Z</kbd> (Undo) / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> (Redo) |
|               | **Adjust Height** | `click-and-drag` the resize handle                                                         |
|               | **Reset Height**  | `double-click` the resize handle                                                           |
|               | **Minimize**      | `double-click` again after resetting height                                                |
|               | **Auto-Resize**   | Toggle the **Fit to content** checkbox                                                     |
| **Canvas**    | **Focus**         | <kbd>Esc</kbd> to focus the canvas                                                         |
|               | **Zoom**          | <kbd>Alt</kbd> + `scroll-wheel` to zoom                                                    |
|               | **Pan**           | <kbd>Space</kbd> + `drag` (or `right-click-and-drag`) to pan                               |
|               | **Reset View**    | `double-click` the canvas to reset view                                                    |
| **Themes**    | **Focus**         | <kbd>Tab</kbd> to focus the theme panel                                                    |
|               | **Navigate**      | <kbd>ArrowUp</kbd> / <kbd>ArrowDown</kbd> to cycle through themes                          |
|               | **Open Source**   | `double-click` a theme to open it in a new window                                          |
|               | **Import**        | `click` the **Load themes** button to import and overwrite existing themes                 |
|               | **Save**          | `click` the **Export theme** button to export your current color configuration             |
| **Workspace** | **Export**        | <kbd>Ctrl</kbd>+<kbd>S</kbd> or click the **Export** button to open export options         |
|               | **Clear All**     | Click the **Reset** button to clear theme selection and view state                         |
